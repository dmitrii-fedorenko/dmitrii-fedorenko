## What I am building
**[Opyt Bez Opyta](https://github.com/dmitrii-fedorenko/opyt-bez-opyta)** is an HRTech marketplace connecting students and businesses. Its code includes task workflows, student and company accounts, submissions and revisions, ratings, portfolios, calendars and subscription-based access rules.

The current RC3.7 build is at the testing / pre-launch stage. Financial-provider workflows and external-service validation remain in progress. Planned features are distinguished from implemented code in the project overview.
